# Attribution Investigator

Build a polished frontend application for the VASP Attribution Engine. First read the attached phases.md and vasp-attribution-master-reference.md; they are the behavior source of truth. Also examine the attached FastAPI backend files and public repo https://github.com/QuantumDev-CERN/VASP-Attribution-Engine.git. Create a defensive AML/compliance investigative console for compliance officers and researchers: case intake, live-style monitoring, interactive fund-flow graph, address/node evidence sidebar, alerts and risk flags, case timeline, confidence attribution, investigation-ready report view, SAHYOG simulated intake, and explicit scope/probabilistic disclosures. Support clear selectable forensic simulation flows for Exchange Inflow, Mixer Detection, Tumbler Routing, Advanced Typologies (chain hop, peeling chain, bridge), and Endpoint/Dead-End analysis. Make it feel credible and usable, responsive, with rich mock case data mapped to the documentation and API integration readiness for the supplied backend endpoints. Do not position it as a tool to evade tracing.
